MUNIN — MASSIVE LOG VIEWER
OFFICIAL RELEASE NOTES — VERSION 2026.10.17.0

1. SYSTEM OVERVIEW AND PURPOSE
--------------------------------------------------------------------------------
Munin App is a high-performance application developed for software engineers, system administrators, security analysts (SOC/SIEM), and infrastructure and DevOps teams who need to inspect, navigate, and analyze massive log files — from routine files of dozens of megabytes to gigantic records of multiple gigabytes (1 GB, 5 GB, 20 GB or more).
Unlike conventional text editors and viewers that attempt to load the entire file into RAM (causing sluggishness, freezes, or crashes due to memory exhaustion), Munin App was architected from its inception to ensure instantaneous opening, smooth 60 frames per second scrolling, minimal and predictable computational resource consumption, high-speed parallel search, and real-time monitoring.

2. MEMORY ARCHITECTURE: WIN32 MAPPING (ZERO-COPY)
--------------------------------------------------------------------------------
Munin App's core is based on deep integration with native Microsoft Win32 API  rimitives:
- File Opening and Mapping: Uses CreateFileW with full sharing (FILE_SHARE_READ | FILE_SHARE_WRITE) and CreateFileMappingW combined with MapViewOfFile in the 64-bit virtual address space.
- Zero Latency on Startup: Files are opened virtually instantaneously (< 1 ms), without blocking disk read operations.
- Predictable RAM Consumption: The application's memory consumption remains stable and reduced to a few megabytes, regardless of whether the inspected file has 100 megabytes or dozens of gigabytes, as the operating system manages memory pages on demand via the Windows virtual memory subsystem.
- Broad Encoding Compatibility: Robust support for UTF-8, ANSI, and ASCII character streams, preserving special characters and graphic accents.

3. HARDWARE-ACCELERATED VECTOR INDEXING (SIMD AVX2 / SSE4.2)
--------------------------------------------------------------------------------
To enable high-speed paging and random jumping, Munin App implements a line break indexing subsystem optimized directly at the hardware level:
- AVX2 Vectorization (256 bits): Processing of 32 simultaneous bytes per vector instruction cycle for immediate detection of line break characters ('\n').
- SSE4.2 Vectorization (128 bits): Processing of 16 simultaneous bytes per cycle on processors with legacy instruction sets.
- Portable Scalar Fallback: High-efficiency scalar algorithm in standard C++ if the hardware does not support vector instructions.
- Indexing Throughput Exceeding 3 GB/s: Line scanning at speeds close to the maximum bandwidth of the memory bus and NVMe subsystem.
- Sparse Block Indexing (ChunkIndex): Structuring in 64 KB blocks that enables calculation and jumping to any line in O(1) time, without the need to maintain pointer tables of all lines in RAM.

4. ASYNCHRONOUS REAL-TIME MONITORING (LIVE TAIL)
--------------------------------------------------------------------------------
Munin App incorporates a continuous monitoring pipeline for live logs:
- Direct Windows Kernel Notifications: Implemented on top of the ReadDirectoryChangesW API on a dedicated background thread.
- Zero Polling and 0% CPU at Idle: Complete elimination of busy-waiting loops ('busy-waiting' or frequent Sleep calls), ensuring zero processing consumption while the file receives no new writes.
- Fluid Tracking: Automatic and immediate detection of new bytes appended to the end of the file by other processes or operating system services.
- Smart Scrolling (Auto-Scroll): Ability to lock scrolling at the bottom edge to follow live events, or allow manual navigation through previous records without new lines interrupting reading.

5. MULTI-CORE PARALLEL SEARCH ENGINE AND FILTERING
--------------------------------------------------------------------------------
Munin App's search tool was designed to respond instantaneously even in datasets with tens of millions of lines:
- Multithreaded Batch Distribution: The mapped file is partitioned into contiguous chunks and distributed dynamically among all logical CPU cores.
- Regular Expressions with JIT Compilation: Support for complex regex patterns through Qt's Just-In-Time compilation engine (PCRE2 JIT).
- Sensitivity Modes: Fast toggle between case-insensitive and case-sensitive search.
- Exclusive Filtering Mode (Matched-Lines Only): Allows hiding all non-matching lines, displaying strictly the entries that match the search pattern.
- Visual Highlighting and Fast Navigation: Real-time visual highlighting of matches with quick navigation shortcuts to previous (F3) and next (Shift+F3) occurrences.

6. TEMPORAL ACTIVITY HISTOGRAM (TIME-SLICE)
--------------------------------------------------------------------------------
To transform raw textual data into clear chronological intelligence:
- Automatic Timestamp Recognition: Native support for ISO 8601 and RFC 3339 formats, traditional date/time stamps from web servers, databases, and operating systems.
- Flexible Interval Grouping: Configurable event segmentation by slices of seconds, minutes, or hours.
- Visual Mapping of Surges and Anomalies: Interactive chart with color-coded identification of activity peaks and anomalous concentration of error events (ERROR, CRITICAL, FATAL).
- Bidirectional Click Navigation: Clicking on any bar of the histogram immediately repositions the reader's view to the first line of that interval.

7. VIRTUALIZED VIEW AND DENSITY MINIMAP (MINIMAP)
--------------------------------------------------------------------------------
Munin App's visualization interface was developed to offer extreme fluidity:
- Strictly Virtualized Rendering (LogView): Exclusively renders lines visible in the current viewport, eliminating unnecessary graphical allocations and ensuring immediate interface responsiveness under any data volume.
- Scroll Bar with Thermal Minimap (MinimapScrollBar): Contiguous vertical channel that draws a miniature density map of the entire file.
- Visual Severity Indicators: Visual display of red bands (errors), yellow bands (warnings), and blue/green bands (search matches), allowing critical file regions to be diagnosed without the need to scroll manually page by page.

8. STRUCTURED LINE INSPECTOR AND JSON LOGS
--------------------------------------------------------------------------------
Designed for modern microservices, cloud, and container environments:
- Automatic Structured Parser: Detects JSON payloads embedded in any log line.
- Interactive Hierarchical Tree: Organizes keys, values, arrays, and nested objects in a tree with instantaneous expansion and collapse.
- Syntax Highlighting: Clear differentiation of strings, numeric values, booleans, and nulls for agile reading.
- Practical Export Actions: Single-click buttons to copy the original raw line, copy formatted JSON with readable indentation, or copy the key of the selected node.

9. BUILT-IN SYNTHETIC LOG GENERATOR FOR BENCHMARKS
--------------------------------------------------------------------------------
For performance validation, proofs of concept, and team training:
- Built-In Generation Tool: Integrated dialog accessible via the Tools menu.
- Standardized Predefined Volumes: Generation of synthetic files of 100 MB, 500 MB, and 1 GB with realistic records.
- Structural Data Diversity: Production of varied lines combining headers, severities, thread identifiers, and JSON objects formatted with high fidelity.

10. DYNAMIC RUNTIME INTERNATIONALIZATION
--------------------------------------------------------------------------------
Munin App features a dynamic and flexible localization system:
- Integrated Official Languages: Portuguese (Brazil - pt_BR) and English (United States - en_US).
- Instantaneous Switching: Language change via the settings menu is applied immediately to all interface components — menu bars, toolbars, side panels, help dialogs, informative footers, and tooltips — without requiring an application restart.

11. WINDOWS 11 VISUAL INTEGRATION AND AUTOMATIC THEME ADAPTATION
--------------------------------------------------------------------------------
The application was designed to harmonize with modern Windows visual standards:
- Automatic Synchronization with Operating System: The interface dynamically detects and follows the Windows 11 theme preference (Light or Dark).
- Native DWM Integration (Desktop Window Manager): Application of Win32 attributes via DwmSetWindowAttribute for seamless rendering of title bars in harmony with the system's active theme.
- Ergonomic High-Contrast Palette: Selected colors for maximum readability and comfort during long periods of technical auditing.
- Independent Modeless Dialog Architecture: Auxiliary windows ('About' and 'Instruction Manual') operate in a non-blocking manner with Z-Order management, allowing free overlay of the main window without focus restrictions.

12. PRIVACY, SECURITY, AND STRICTLY LOCAL OPERATION
--------------------------------------------------------------------------------
Munin App was designed with an uncompromising focus on data protection, secrecy, and integrity:
- 100% Autonomous and Offline: Munin App operates strictly in a local and offline environment.
- Zero Telemetry and Zero Tracking: No usage log, statistic, identifier, or behavioral information is collected, stored, or sent to the internet.
- Absolute Data Secrecy: The content of analyzed logs never leaves the user's machine, making Munin App suitable for corporate environments with strict compliance policies (LGPD, GDPR, HIPAA, SOC 2).
