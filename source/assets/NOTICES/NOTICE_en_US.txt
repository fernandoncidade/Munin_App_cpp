2. Native Windows APIs and Microsoft Windows SDK
Usage in the project:
- Virtual memory mapping of files (Memory-Mapped Files) for instantaneous opening and on-demand zero-copy navigation across massive multi-gigabyte files;
- Real-time filesystem monitoring for newly appended log entries (Live Tail);
- Real-time query of physical application memory usage (RAM);
- Modern Windows desktop theme integration (Windows 11 DWM Mica, Dark Mode, and Light Mode).

Linked Components and Libraries:
- `kernel32.lib` (CreateFileW, CreateFileMappingW, MapViewOfFile, UnmapViewOfFile, CloseHandle, GetFileSizeEx for virtual page mapping);
- `kernel32.lib` (ReadDirectoryChangesW for asynchronous Live Tail file monitoring);
- `dwmapi.lib` (DwmSetWindowAttribute for Dark Mode and modern window framing support in Windows 11);
- `psapi.lib` (GetProcessMemoryInfo for tracking process RAM usage displayed in the status bar);
- `user32.lib`, `shell32.lib`.

Licensing Note:
- These components are integral parts of the Microsoft Windows operating system and Microsoft Windows SDK;
- They are invoked via standard operating system platform APIs and are not redistributed by this project as separate open-source libraries.
