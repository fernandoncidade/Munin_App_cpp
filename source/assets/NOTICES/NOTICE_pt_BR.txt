2. APIs Nativas do Windows e Microsoft Windows SDK
Uso no projeto:
- Mapeamento virtual de arquivos em memória (Memory-Mapped Files) para abertura instantânea e navegação zero-copy sob demanda em arquivos gigantescos de múltiplos gigabytes;
- Monitoramento em tempo real do sistema de arquivos para novas entradas de log (Live Tail);
- Consulta a métricas de consumo de memória física (RAM) em tempo real da aplicação;
- Integração de temas modernos da área de trabalho do Windows (DWM Mica, Dark Mode e Light Mode).

Componentes e Bibliotecas Vinculadas:
- `kernel32.lib` (CreateFileW, CreateFileMappingW, MapViewOfFile, UnmapViewOfFile, CloseHandle, GetFileSizeEx para mapeamento virtual de páginas);
- `kernel32.lib` (ReadDirectoryChangesW para monitoramento assíncrono de arquivos em Live Tail);
- `dwmapi.lib` (DwmSetWindowAttribute para Dark Mode e suporte a efeitos de janela moderna no Windows 11);
- `psapi.lib` (GetProcessMemoryInfo para monitoramento do consumo de memória RAM do processo exibido na barra de status);
- `user32.lib`, `shell32.lib`.

Observação de Licenciamento:
- Estes componentes fazem parte integrante do sistema operacional Microsoft Windows e do Microsoft Windows SDK;
- Eles são utilizados por meio das APIs padrão do sistema operacional e não são redistribuídos por este projeto como bibliotecas open source avulsas.


3. Instruções Vetoriais SIMD de Hardware (AVX2 e SSE4.2)
Uso no projeto:
- Aceleração vetorial de contagem e indexação de quebras de linha ('\n') em buffers de log a velocidades superiores a 3 GB/s;
- Algoritmos com seleção dinâmica em tempo de execução por detecção de CPU, com fallback escalar seguro e portável em C++20 para compatibilidade universal.

Regime de Licenciamento:
- Os intrínsecos SIMD (<immintrin.h>, <nmmintrin.h>) integram a especificação de hardware x86-64 dos fabricantes de microprocessadores (Intel e AMD) e as bibliotecas padrão dos compiladores C++ suportados.
